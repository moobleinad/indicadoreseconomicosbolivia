# GUÍA DE INTEGRACIÓN CON BLOGGER API v3

**Objetivo:** Permitir que Antigravity (AI Assistant) se conecte a la cuenta de **Blogger** de Daniel Simons para automatizar el traslado de Entradas a Páginas Estáticas, crear publicaciones en Markdown y gestionar contenidos.

---

## PASO 1: Habilitar la Blogger API en Google Cloud (100% Gratuito)

1. Ingresa a la consola de desarrolladores de Google: [https://console.cloud.google.com/](https://console.cloud.google.com/)
2. En la barra superior, haz clic en el selector de proyectos y selecciona **"Nuevo Proyecto"**.
3. Nombra tu proyecto: `Blogger-DanielSimons` y haz clic en **Crear**.
4. En el buscador superior de la consola, escribe **"Blogger API v3"** y selecciónala.
5. Haz clic en el botón azul **Habilitar**.

---

## PASO 2: Obtener las Credenciales (OAuth 2.0 / API Key)

1. Ve al menú lateral izquierdo → **API y servicios** → **Credenciales**.
2. Haz clic en **"+ CREAR CREDANCIALES"** en la parte superior.
3. Selecciona **ID de cliente OAuth**:
   * Tipo de aplicación: **Aplicación de escritorio** (Desktop app).
   * Nombre: `Antigravity Blogger Client`.
   * Haz clic en **Crear**.
4. En la ventana emergente, haz clic en **DESCARGAR JSON**.
5. Guarda el archivo descargado en tu carpeta del proyecto con el nombre:  
   `client_secret.json`  
   *(Ruta: `c:\Users\Usuario\Desktop\antigravity\blogger_danielsimons.xyz\client_secret.json`)*

---

## PASO 3: Ejecución del Script de Migración Automática

Una vez colocado el archivo `client_secret.json`, ejecutaremos el script en Python para:
1. Extraer el contenido de las entradas: *Destilado de Ideas*, *Forja*, *Marketing 360* e *Impulso MYPE*.
2. Crear automáticamente las **Páginas Estáticas** (`/p/...`) en Blogger con formato elegante y SEO.
3. Vincular las nuevas páginas en tu sitio web.
