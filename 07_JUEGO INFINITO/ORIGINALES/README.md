# EL JUEGO INFINITO - REPOSITORIO EDITORIAL

Este repositorio organiza la obra de Daniel Simons como una plataforma intelectual viva.

Su funcion no es reemplazar los documentos originales en Word. Su funcion es convertirlos progresivamente en materiales limpios, publicables y navegables para `juegoinfinito.xyz`.

## Tesis central

La realidad puede entenderse como un juego dinamico de relaciones, individualidades, sistemas, tensiones y transformaciones. Comprender el juego permite actuar con mayor lucidez, preservar tableros futuros y construir mejores formas de cooperacion, libertad, poder y continuidad.

## Arquitectura

```text
00_MANIFIESTO/
  Textos fundacionales de El Juego Infinito.

01_LIBROS/
  Versiones limpias y publicables de cada obra.

02_CONCEPTOS/
  Glosario vivo de conceptos centrales.

03_ARTICULOS/
  Articulos breves para publicar en la web.

04_CASOS/
  Aplicaciones concretas a Bolivia, energia, politica, emprendimiento y sistemas.

05_PRODUCTOS/
  Materiales con potencial de rentabilidad: ebooks, talleres, briefs, servicios.

06_WEB/
  Espacio futuro para el sitio Astro/Cloudflare/Decap.

07_ARCHIVO_EVOLUTIVO/
  Zona para material historico, evaluaciones, borradores y versiones antiguas.
```
