# Glosario Base

## Juego

Proceso mediante el cual las relaciones generan, exploran, transforman y reorganizan posibilidades.

## Relacion

Condicion mediante la cual una existencia puede diferenciarse, interactuar y manifestarse.

## Existencia

Condensacion temporal de relaciones momentaneamente finitas y suficientes para ser.

## Identidad

Patron temporal de relaciones suficientemente estable para distinguir una existencia de otras.

## Tablero

Conjunto de condiciones que hacen posible la continuidad de un juego.

## Jugador Lucido

Individualidad capaz de observar relaciones, reglas, tensiones, consecuencias y posibilidades antes de actuar.

## Estabilidad Dinamica

Capacidad de un sistema para preservar continuidad funcional mientras se transforma.

## Individualidad Relacional

Configuracion de relaciones suficientemente diferenciada para actuar, persistir, transformarse y ser reconocida como unidad relativa.

## MEDS

Modelo de Estabilidad Dinamica Sistemica. Marco conceptual y operacional para observar fragilidad, adaptacion, sensibilidad, propagacion y amplificacion en sistemas complejos.
